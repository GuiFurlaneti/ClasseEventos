🎉 Site Institucional – Classe Eventos

🎯 Site institucional desenvolvido para a Classe Eventos, agência especializada em eventos corporativos, feiras, congressos e ações promocionais de alto padrão em São Paulo. O objetivo foi criar uma presença digital premium, persuasiva e funcional — com foco em conversão via WhatsApp, catálogo completo de serviços organizado por categorias e experiência fluida em qualquer dispositivo.

🔗 Acesse aqui o projeto online:
➡️ [guifurlaneti.github.io/ClasseEventos](https://guifurlaneti.github.io/ClasseEventos/)

🛠️ Tecnologias Utilizadas

* HTML5 semântico com acessibilidade (ARIA)
* Tailwind CSS (via CDN) + CSS customizado
   * Design system com variáveis e gradiente dourado exclusivo
   * Responsividade completa (mobile, tablet e desktop)
   * Glassmorphism e animações suaves
* JavaScript (Vanilla JS)
   * Scroll reveal com `IntersectionObserver`
   * Accordion nos cards de serviços
   * Menu mobile com `aria-expanded`
* Bootstrap Icons
   * Ícones padronizados e coerentes com a identidade visual
* SEO Técnico
   * Meta tags completas, Open Graph, Twitter Card e JSON-LD (LocalBusiness)
   * `robots.txt` e `sitemap.xml`
* Segurança
   * Content Security Policy (CSP), Subresource Integrity (SRI) e Referrer-Policy
* Design Mobile First

🧩 Principais Funcionalidades

✅ Scroll reveal suave em todas as seções ao rolar a página
✅ Header com fundo dinâmico (transparente no topo, sólido ao rolar)
✅ Cards de serviços em formato accordion, cobrindo 9 categorias e mais de 80 serviços
✅ Marquee infinito com logos de clientes reais
✅ Timeline animada com as 5 etapas do processo de trabalho
✅ Múltiplos botões de WhatsApp com mensagem pré-preenchida
✅ Menu mobile com `aria-expanded` e fechamento automático ao navegar
✅ SEO completo com dados estruturados (JSON-LD LocalBusiness)
✅ Favicon real com suporte a dispositivos Apple (apple-touch-icon)
✅ Content Security Policy e Subresource Integrity para proteção contra ataques
✅ Estrutura pronta para ativar Google Ads / GA4 (basta inserir os IDs reais)

📄 Seções do Site

1. Navbar — Fixa, responsiva, com logo, menu e CTA de WhatsApp; menu hambúrguer no mobile
2. Hero — Tela cheia com imagem de fundo, texto alinhado à esquerda e CTA de orçamento
3. Clientes — Marquee infinito com logos de clientes reais
4. Quem Somos — Texto institucional, foto da equipe e 6 diferenciais competitivos
5. Serviços — 9 categorias em cards expansíveis, cobrindo o catálogo completo de serviços
6. Como Trabalhamos — Timeline com as 5 etapas do processo, do briefing à entrega
7. CTA Final — Chamada final para solicitação de orçamento
8. Footer — Links rápidos, contatos (e-mail, WhatsApp, telefone, endereço) e direitos autorais

🚀 Como Rodar Localmente
Não requer instalação. Basta clonar o repositório e abrir o arquivo `index.html` no navegador:

```
git clone https://github.com/GuiFurlaneti/ClasseEventos.git
cd ClasseEventos
# Abra o index.html no seu navegador
```
